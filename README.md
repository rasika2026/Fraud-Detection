
# Credit Card Fraud Detection Using Machine Learning

## Project Overview
This project detects fraudulent credit card transactions using Machine Learning and a Support Vector Machine (SVM) with a linear kernel.

The model analyzes transaction data and classifies transactions as Fraud or Non-Fraud.

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Support Vector Machine (SVM)

## Project Features
- Credit card transaction analysis
- Fraud and non-fraud classification
- Data visualization
- Correlation heatmap
- Fraud transaction analysis
- Confusion matrix
- Model evaluation

## Project Structure
Credit-Card-Fraud-Detection/
│
├── fraud_detection.py

└── README.md

## Dataset
The project requires a CSV dataset containing:
- Time
- Amount
- Class

Class 0: Non-Fraud
Class 1: Fraud

Note: The dataset is not included in this repository.

## Installation

Install the required libraries:

pip install -r requirements.txt

## How to Run

Run the Python file:

python fraud_detection.py

Select your credit card transaction CSV dataset when prompted.

## Machine Learning Algorithm
Support Vector Machine (SVM) with a Linear Kernel.
